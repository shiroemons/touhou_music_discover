# 配信サービス間の楽曲表記・位置ずれ調査（2026-08-02）

開発DBの `東方流星少女//改二` について、原曲紐づけ移行の候補調査中に配信サービス間の差異を確認した。原曲移行機能とは別の問題として記録し、この調査では配信データの修正・削除を行っていない。

## 対象

- 既存JAN: `4580547336436`
- 新JAN: `4580547336023`
- サークル: 魂音泉

## 確認結果

- LINE MUSIC: 両JANとも8曲が同じ位置・曲名・ISRCで一致する。
- Spotify: 両JANとも8曲の位置とISRCは一致するが、新JAN側に英語表記やメタデータ表記差がある。例: `Milky Way//改二` と `Milky Way//Second Upgrade`、`紅楼` と `KOUROU`。
- Apple Music: 新JAN側は1曲目がなく、位置2〜8の7曲だけが保存されている。
- YouTube Music: 新JAN側は曲数が不足し、保存された曲名と基底TrackのISRCが1位置ずつずれている可能性が高い。

## 原曲移行機能での扱い

- Spotifyの曲名を正規データとして補正・上書きしない。
- 完全で連続したカタログだけを比較に使う。
- 同じ位置で、両側をNFKC・英字大小・連続空白について正規化した曲名が一致するか、ISRCが一致することを全曲で確認する。
- 正規化後も曲名が異なる場合は文字列一致度を表示するが、一致度だけでは自動移行しない。
- 今回はLINE MUSIC同士の完全一致を移行根拠として採用する。

## 別途調査する事項

- Spotifyで英語曲名が取得される条件とAPIレスポンスのロケール依存性。
- Apple Musicで1曲目が取得されない理由（配信可否、ストアフロント、API結果）。
- YouTube Musicの欠落曲発生時に、位置だけでApple Music/Spotifyの基底Trackへ割り当てていないか。
